# Home Network Assessment

Security Audit of local network.  Data was anonymized before upload to git.

## Process
1. **Define Scope and Goals:** Decide which systems, cloud services, and devices to check, and align your targets. See: [Scope](scope.md)
1. **Gather Asset Inventory:** List all hardware, software, user accounts, and critical data stores.  See: [Inventory](inventory.md)
1. **Review Policies and Controls:** Check firewall rules, multi-factor authentication (MFA) setup, role-based access control (RBAC), and patch levels. 
1. **Scan and Test:** Run vulnerability scans and penetration tests using tools like Nessus or Wireshark to find active security holes. 
1. **Analyze and Report:** Document your findings, rate risks by severity, and detail plans for improvements
